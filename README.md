# Parents Connectés

Site pour les parents d'enfants de 0 à 3 ans : fil d'actualités façon Instagram avec des conseils, des défis de la semaine, des quiz et des activités.

## Organisation

- `design-system/` : tokens, composants CSS et page de démo (partie visuelle)
- `assets/icones/` : icônes SVG du site
- Front-end, back-end et base de données : à venir
